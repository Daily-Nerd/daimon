=== write-checkpoint ===
usage: daimon write-checkpoint [-h] [--project PROJECT] [--source SOURCE] [--session SESSION]
options: -h, --help show this help message and exit --project PROJECT project directory to route the
checkpoint to (default: DAIMON_PROJECT_DIR, then cwd) --source SOURCE provenance stamp for the
