# Security Policy

## Reporting a vulnerability

Please report security problems privately. Do not open a public issue or
discussion for a vulnerability.

Use GitHub private vulnerability reporting: open the Security tab of this
repository and choose "Report a vulnerability", or go straight to
https://github.com/Daily-Nerd/daimon/security/advisories/new

Helpful things to include:

- the affected version (`daimon --version`) and your OS and Python version
- what you did, what you expected, and what happened instead
- the smallest reproduction you can manage (commands, a sample checkpoint or
  config, logs with secrets removed)
- what you think the impact is, if you have a view on it

## What to expect

This is a small project with a small maintainer team. We will read your report
and reply within about a week. If it is a real vulnerability we will tell you
how we plan to handle it, work on a fix, and agree on disclosure timing with
you. We cannot promise a fixed time to a fix, since that depends on the
severity and the size of the change, but we will keep you updated. Once a fix
is released we are happy to credit you in the advisory if you want that.

## Supported versions

Only the latest release receives security fixes. Please check that the problem
still exists on the newest version before reporting.
